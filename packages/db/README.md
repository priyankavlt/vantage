# @vantage/db

Drizzle schema and migrations for Vantage's own metadata (users, workspaces, data sources, …).

- Auth tables in `src/schema/auth.ts` are generated by better-auth: `pnpm --filter @vantage/server auth:generate`.
- After changing any schema file: `pnpm --filter @vantage/db db:generate --name <change>` and commit the SQL in `drizzle/`.
- The server applies pending migrations on startup.
